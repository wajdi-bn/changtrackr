\section{Résultat de la campagne}

La campagne du 17/08/2026 a été exécutée sur la révision
\texttt{8e30530}. Les tests Laravel ont été exécutés localement avec SQLite en
mémoire ; le gateway OCPP a été reconstruit et testé dans son image Docker. La
CI complète répète en plus les migrations et les tests critiques avec
PostgreSQL et Redis.

\section{Observations automatiques}

\begin{testbox}{Avertissement non bloquant}
Le build Vite réussit. Le worker PDF généré dépasse 1~MB et plusieurs modules
fonctionnels restent volumineux, notamment les aperçus PDF et le scanner QR.
Le découpage dynamique limite le bundle initial, mais une campagne de mesure
réseau reste nécessaire avant une montée en charge importante.
\end{testbox}
