\section{Observations automatiques}

\begin{testbox}{Avertissement non bloquant}
Le build Vite réussit, mais signale plusieurs chunks minifiés supérieurs à
500~kB, notamment les bibliothèques PDF, QR et le bundle principal. Cette
observation est classée S3 performance : elle nécessite du découpage
supplémentaire avant une mise en production à grande échelle, sans bloquer la
recette fonctionnelle du MVP.
\end{testbox}
