# Cahier des charges initial

Le fichier `original/cahier-des-charges-fonctionnel-v1.0.pdf` est la copie
immuable du cahier des charges fonctionnel transmis par TAC-TIC Tunisie au
démarrage du stage.

Il reste la référence d'origine et ne doit pas être réécrit pour refléter
rétroactivement les décisions du projet. Les adaptations, réalisations
partielles et fonctionnalités reportées sont tracées dans l'annexe A du rapport
de stage :

`docs/report/output/pdf/charge-trackr-rapport-stage.pdf`

Cette séparation permet de distinguer clairement :

- le besoin initial fourni par l'entreprise ;
- le périmètre effectivement validé dans le Product Backlog ;
- les preuves de réalisation et les limites du MVP.
